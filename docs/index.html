Why your Bitget account is not connected here

This is a public static website. Anything a public page uses (including an API key) can be read by anyone who opens it, so account access (balances, positions, orders) does not belong here. Account-level tools will run locally on your own PC from the bgbot lab code, with a read-only, IP-bound, withdrawal-disabled key kept in an environment variable — never in this repository, never in a browser.
